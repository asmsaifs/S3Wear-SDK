# S3Wear developer documentation

Build mini apps and watch faces for the S3Wear smartwatch. Apps are WebAssembly modules written in C or Rust against one
header; faces are data files. Everything here runs in the desktop simulator, so you can start without a watch.

| Start | |
|---|---|
| [Overview](start/overview.md) | What runs where, and what you need |
| [Install the SDK](start/install.md) | The CLI, a compiler, the simulator, or the dev container |
| [Your first app (C)](start/first-app-c.md) · [(Rust)](start/first-app-rust.md) | A counter in five minutes |
| [Your first game](start/first-game.md) | A canvas, a frame loop, input |
| [Your first watch face](start/first-face.md) | A `face.json` in one file |

Then read the [concepts](concepts/lifecycle.md), pick [guides](guides/widgets.md) for what you build, and keep
[the API reference](api/index.md) open.
