# s3w

Command-line tool for S3Wear mini apps: `new`, `build`, `pack`, `sign`, `run-sim`, `install`, `logs`, and `sim install|update|list` (the simulator binary from the firmware site, checked against the release key).

    pipx install s3w
    s3w new my-app && s3w build my-app

Docs: https://s3wear.fiqraat.com/developers/
